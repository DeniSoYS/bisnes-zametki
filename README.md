# Бизнес заметки

Простое приложение на React Native / Expo для заметок и ссылок. Работает в браузере телефона и сохраняет записи локально на устройстве через `AsyncStorage`.

## Важно про сохранение

Сейчас база локальная: записи сохраняются только в браузере/на устройстве, где ты их добавил. Если открыть сайт на другом телефоне или очистить данные браузера, там будет отдельная пустая база.

Если нужно, чтобы записи были одинаковые на всех устройствах, нужна облачная база данных и вход в аккаунт, например Supabase/Firebase.

## Запуск локально

```bash
npm install
npm run web
```

После запуска Expo покажет локальный адрес. Его можно открыть с телефона, если телефон и компьютер в одной Wi-Fi сети.

## Сборка для Vercel

```bash
npm run build:web
```

Готовые файлы появятся в папке `dist`.

## Деплой на Vercel

1. Загрузи проект в GitHub.
2. На Vercel нажми **Add New Project**.
3. Выбери репозиторий.
4. Vercel возьмёт настройки из `vercel.json`:
   - Build command: `npm run build:web`
   - Output directory: `dist`
5. После деплоя Vercel даст бесплатный домен вида `project-name.vercel.app`.

## Что уже есть
